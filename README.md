# TO-DO-LIST

# 📝 To-Do List Application (Tkinter)

A simple **To-Do List desktop application** built using **Python and Tkinter**.  
This app allows users to add, delete, save, and load tasks automatically.

---

## 🚀 Features

- ➕ Add new tasks  
- ❌ Delete selected tasks  
- 💾 Save tasks to a JSON file  
- 🔄 Load tasks automatically on app start  
- 🖥️ Simple and beginner-friendly GUI  

---

## 🛠️ Technologies Used

- Python 🐍
- Tkinter (GUI)
- JSON (for data storage)

---

## 📂 Project Structure

```

├── main.py          # Main application file
├── task.json        # Stores saved tasks
└── README.md        # Project documentation

````

